# tamper-detect —— 无参考视频篡改检测工具

只凭**单个视频文件自身**的编码结构、时间戳、画面噪声与场景连续性, 检测监控录像中的
**删帧、插帧、拼接、画面局部替换**四类篡改, 标出可疑时间段并给出量化依据。不需要原始录像对照。

## 构建

依赖: FFmpeg 开发库(libavformat / libavcodec / libavutil / libswscale), C++17 编译器。

```bash
make            # 产出 build/tamper-detect
```

## 使用

```bash
./build/tamper-detect [选项] <视频文件>
  --json <file>     输出结构化 JSON 报告
  --csv  <file>     输出逐帧通道分数 CSV(便于复核/调参)
  --width <px>      分析用灰度宽度, 默认 320(越小越快)
  --threshold <f>   报警分数阈值 0..1, 默认 0.45
  -v                verbose
```

退出码: `0` = 未发现超阈值片段, `1` = 有发现(便于脚本串联)。

## 检测原理: 五个独立通道 + 证据融合

工具流式解码全片, 逐帧提取特征(只保留两份灰度图, 内存约 O(帧数)):

| 通道 | 依据的痕迹 | 主要对应篡改 |
|------|-----------|-------------|
| 1 时间戳/容器 | 帧间隔偏离帧率周期(整周期缺失/异常缩短)、PTS 回退 | 未重编码的删帧、插帧 |
| 2 编码结构 | GOP/IDR 周期与相位断裂、码率突变、运动向量不连续、QP 突变(若可导出) | 重编码删帧、拼接 |
| 3 噪声指纹 | 全帧噪声水平的阶跃(前后窗均值差, IQR 自适应归一化) | **异源拼接**的决定性证据 |
| 4 场景连续性 | 帧间 SAD 突变、连续近重复帧簇、亮度阶跃 | 删帧内容跳变、冻结式插帧 |
| 5 局部区域 | 8×6 网格块各自的噪声/高频能量相对**自身时间基线**异常, 加起变点、空间成簇、位置固定约束 | **画面局部替换/遮盖** |

### 关键判据组合(fuse.cpp)

- **异源拼接**: 噪声指纹阶跃 + (编码结构异常 或 帧间不连续)。同源剪辑噪声连续, 不会触发。
- **重编码删帧**(时间戳已被抹平): GOP 相位不可恢复地偏移 / 帧间 SAD 突增 + 编码异常,
  且排除自然场景硬切。这是无参考场景下最难的一类, 置信度相应保守。
- **冻结/复制插帧**: 连续多帧与前一帧近乎完全相同而 PTS 仍推进 —— 独立强证据, 直接成案。
- **局部替换**: 异常块必须①相对自身时间基线突变(起变点)②空间 4-连通成紧凑簇
  ③位置固定持续 ≥5s ④与相邻正常块有锐边。运动物体因位置漂移、持续短而被排除。

## 性能

1 小时 320×240 H.264(9 万帧): 解码约 90s + 分析约 0.5s, **约 40× 实时**, 峰值内存 ~130MB。
分析阶段是线性 O(n), 耗时主要在解码; 调小 `--width` 可进一步加速。

## 测试素材(全部由 ffmpeg lavfi 合成, 无外部依赖)

```bash
bash tests/gen_samples_cam.sh     # 固定机位监控场景(推荐): 静止噪声背景+移动目标
bash tests/gen_samples_real.sh    # 平滑动态场景(mandelbrot/life)
bash tests/gen_samples.sh         # 原始合成场景(testsrc2, 含密集场景切换, 偏对抗)
bash tests/run_tests.sh cam       # 自动化评测, 与 ground truth 对照
```

`tests/gen_samples_cam.sh` 生成 1 个原始片、1 个阴性对照(同源硬切)和 5 类篡改片,
`run_tests.sh` 全部通过(7/7): 阴性零误报, 5 类篡改均在真值时间 ±0.5s 内检出。

## 能力边界(无参考检测的固有局限, 结论需人工复核)

- 同源删帧后**整体重编码**会重写时间戳, 只能靠编码相位/帧间不连续间接推断,
  与自然场景硬切存在特征重叠 —— 工具用噪声连续性和硬切强度区分, 但非绝对。
- 若篡改后以与原片完全相同的参数对全片重新编码、且接缝恰好在自然 GOP 边界,
  编码层痕迹会大幅减弱, 此时主要依赖噪声/内容通道, 置信度下降。
- 局部替换检测假设固定机位、背景基本稳定; 全画面持续运动(如手持/变焦)会降低其可靠性,
  这类场景主要依赖前四个全局通道。
- 输出的是**统计嫌疑与依据**, 不是法律意义上的鉴定结论。
- QP 逐帧 side data 仅在编码侧可导出, 解码第三方文件时通常不可得, 工具自动降级跳过该子信号。
